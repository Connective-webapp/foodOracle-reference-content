Un couvert correspond à une personne servie dans le restaurant pendant une prestation. Le nombre de couverts est comptabilisé par service, le midi et le soir, et il est la base de presque tous les indicateurs de salle, comme le ticket moyen ou le taux de remplissage.

Le terme désigne aussi, dans les usages, le couvert de table, c'est-à-dire l'ensemble des couverts posés. Il ne faut pas confondre les deux usages. Pour les calculs, on retient le nombre de clients servis, que les caisses et les réservations permettent de suivre.
