Dans le vocabulaire de la restauration, la note désigne l'addition d'une table, surtout dans le langage oral entre serveurs. On dit demander la note pour réclamer le compte. Le mot est familier et plus courant dans la restauration traditionnelle que dans les établissements récents.

Le terme renvoie aussi à la note de commande, qui est le ticket transmis du service à la cuisine. Cette double acception exige de préciser le sens selon le contexte. Dans une fiche de formation, on indique la note de commande pour le ticket et l'addition pour le document du client.
